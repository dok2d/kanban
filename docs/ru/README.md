# Документация Kanban

Минималистичный self-hosted канбан со спринтами, эпиками, тегами, комментариями, уведомлениями, интеграцией с Telegram и drag-and-drop.

## Содержание

1. [Быстрый старт](getting-started.md) — установка, первый запуск, создание администратора
2. [Руководство пользователя](user-guide.md) — работа с доской, задачами, спринтами и эпиками
3. [Аутентификация и роли](authentication.md) — локальная авторизация, LDAP, OIDC, управление пользователями
4. [Развёртывание](deployment.md) — контейнер, systemd, nginx, TLS
5. [Конфигурация](configuration.md) — флаги запуска, переменные окружения, настройки
6. [Telegram-бот](telegram.md) — настройка бота, привязка аккаунта, команды
7. [Резервное копирование](backup.md) — бэкапы, экспорт и импорт данных
8. [Безопасность](security.md) — хардинг контейнера, шифрование, защита данных
9. [REST API](api.md) — справочник по всем эндпоинтам
10. [Темы и локализация](themes-and-i18n.md) — темы оформления, языки, размер шрифта
