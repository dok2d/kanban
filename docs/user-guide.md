# Руководство пользователя

## Доска

Основной экран — канбан-доска с колонками. Каждая колонка представляет этап работы (например, «To Do», «In Progress», «Done»). Задачи отображаются как карточки, которые можно перетаскивать между колонками.

### Управление колонками

- Администратор может создавать, переименовывать, переупорядочивать и удалять колонки
- Первую (Backlog) и последнюю (Done) колонки удалить нельзя
- Порядок колонок настраивается перетаскиванием

### Фильтрация

В шапке доски доступны фильтры:

- **⬡ kanban** — показать все задачи (без фильтрации)
- **Спринт** — фильтр по спринту (по умолчанию показывается самый старый активный)
- **Эпик** — фильтр по эпику

## Задачи

### Создание задачи

Нажмите «+» в нужной колонке. Укажите:

- **Название** — краткое описание задачи
- **Описание** — подробности в формате Markdown (поддержка подсветки синтаксиса)
- **Приоритет** — без приоритета, низкий, средний, высокий, критический
- **Дедлайн** — опциональная дата, отображается на карточке
- **Спринт** — привязка к спринту (или бэклог)
- **Эпик** — привязка к эпику
- **Теги** — произвольные метки
- **Исполнитель** — назначенный пользователь

### Приоритеты

Приоритет отображается цветной полоской слева на карточке:

| Приоритет    | Цвет    |
|-------------|---------|
| Низкий      | синий   |
| Средний     | жёлтый  |
| Высокий     | оранжевый |
| Критический | красный |

### Markdown в описании

Описание задачи поддерживает Markdown:

- Заголовки, списки, ссылки, изображения
- Блоки кода с подсветкой синтаксиса (highlight.js)
- **TODO-списки** — интерактивные чекбоксы (`- [ ]` / `- [x]`), можно отмечать прямо в карточке

### Зависимости

Задачи могут иметь зависимости:

- **Зависит от** — задача не может быть выполнена, пока не закрыта другая
- **Блокирует** — эта задача блокирует выполнение другой

### Вложения

- **Изображения** — вставка через Ctrl+V (автоматическое сжатие до ~500 КБ)
- **Файлы** — PDF, текстовые файлы, архивы и другие форматы

## Спринты

Спринты помогают организовать работу по итерациям.

### Статусы спринта

1. **Планирование** — спринт создан, задачи добавляются
2. **Активный** — работа идёт
3. **Завершён** — спринт закрыт

### Завершение спринта

При завершении спринта незакрытые задачи автоматически переносятся в следующий активный спринт.

### Бэклог

Задачи без спринта попадают в бэклог — общий список задач, которые ждут планирования.

## Эпики

Эпики — это крупные инициативы, объединяющие несколько задач. Каждый эпик имеет:

- Название и описание
- Цветовую маркировку (отображается на карточках)
- Индикатор прогресса (доля завершённых задач)

## Теги

Теги — произвольные метки для категоризации задач. У задачи может быть несколько тегов. Теги доступны в поиске.

## Комментарии

- Вложенные комментарии с ответами (threading)
- Поддержка Markdown и подсветки синтаксиса
- **@упоминания** — при упоминании пользователь получает уведомление

## Поиск

Поиск доступен в шапке доски. Поддерживаются два режима:

- **Обычный текст** — поиск по вхождению подстроки
- **Regex** — поиск по регулярному выражению

Поиск работает по: названиям задач, описаниям, комментариям, тегам, эпикам.

## Уведомления

Уведомления приходят при:

- Назначении задачи на вас
- @упоминании в комментарии
- Обновлении задачи, на которую вы подписаны
- Новом комментарии к подписанной задаче

Можно подписаться на задачу через кнопку подписки в карточке. Уведомления доступны в приложении и через [Telegram-бот](telegram.md).

## Лента активности

Каждый пользователь имеет ленту активности с подробной историей изменений: создание задач, изменения статусов, комментарии и другие действия. Отображаются последние 100 записей.
