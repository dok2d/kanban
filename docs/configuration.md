# Конфигурация

## Флаги запуска сервера

Сервер (`cmd/server/main.go`) принимает следующие флаги:

| Флаг       | Описание                  | По умолчанию   |
|------------|---------------------------|-----------------|
| `-addr`    | Адрес и порт сервера      | `:8080`         |
| `-db`      | Путь к файлу БД SQLite    | `/data/kanban.db` |
| `-verbose` | Подробное логирование     | `false`         |

## Флаги kanban.sh

Для команд `run` и `deploy`:

| Флаг              | Описание                        | По умолчанию                    |
|-------------------|---------------------------------|---------------------------------|
| `--host <value>`  | FQDN или IP-адрес               | `kanban.local`                  |
| `--port <port>`   | Порт (nginx + контейнер)        | `443` (TLS) / `80` (HTTP)      |
| `--tls`           | Включить TLS (HTTPS)            | включён                        |
| `--no-tls`        | Только HTTP, без TLS            | —                               |
| `--cert <path>`   | Путь к TLS-сертификату          | `/etc/nginx/ssl/kanban.crt`    |
| `--key <path>`    | Путь к TLS-ключу                | `/etc/nginx/ssl/kanban.key`    |

## Переменные окружения

Альтернатива флагам — переменные окружения:

| Переменная         | Соответствует флагу |
|--------------------|---------------------|
| `KANBAN_HOST`      | `--host`            |
| `KANBAN_PORT`      | `--port`            |
| `KANBAN_TLS`       | `--tls` / `--no-tls`|
| `KANBAN_SSL_CERT`  | `--cert`            |
| `KANBAN_SSL_KEY`   | `--key`             |

## Настройки в интерфейсе

### Тема оформления

8 тем на выбор: dark, light, ocean, forest, nord, dracula, solarized, spacedust. Выбор сохраняется в localStorage браузера.

### Язык

10 языков: русский, английский, китайский, испанский, французский, немецкий, португальский, японский, корейский, арабский.

### Размер шрифта

Настраиваемый размер шрифта (по умолчанию 18px).

### Часовой пояс

Администратор может установить серверный часовой пояс через настройки:

```
POST /api/settings/timezone
{"timezone": "Europe/Moscow"}
```

### Telegram-бот

Настройка в разделе «Settings → Telegram» (только для администраторов). Подробнее — [Telegram-бот](telegram.md).

## База данных

- SQLite с режимом WAL (Write-Ahead Logging) для параллельного доступа
- Поддержка внешних ключей
- Автоматические миграции при запуске
- Путь к БД задаётся флагом `-db`
