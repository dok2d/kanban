# Telegram-бот

Интеграция с Telegram позволяет получать push-уведомления и управлять задачами из мессенджера.

## Настройка бота

### 1. Создание бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

### 2. Настройка в приложении

1. Войдите как администратор
2. Откройте **Settings → Telegram**
3. Введите токен бота и имя пользователя бота (без @)
4. Сохраните

### 3. Привязка аккаунтов

Каждый пользователь привязывает Telegram самостоятельно:

1. В профиле нажмите «Привязать Telegram»
2. Скопируйте сгенерированный код
3. Отправьте этот код боту в Telegram
4. Аккаунт привязан

Для отвязки используйте кнопку «Отвязать Telegram» в профиле.

## Команды бота

| Команда              | Описание                                   |
|----------------------|--------------------------------------------|
| `/tasks`             | Список назначенных на вас задач            |
| `/task N`            | Подробности задачи #N с последними комментариями |
| `/comment N текст`   | Добавить комментарий к задаче #N           |
| `/help`              | Список доступных команд                    |

## Уведомления

Бот отправляет уведомления при:

- Назначении задачи на вас
- @упоминании в комментарии
- Новом комментарии к задаче, на которую вы подписаны
- Обновлении подписанной задачи

## Восстановление пароля

Пользователи с привязанным Telegram могут восстановить пароль:

1. На странице логина нажмите «Забыли пароль?»
2. Введите имя пользователя
3. Бот пришлёт 8-значный код
4. Введите код и задайте новый пароль

## Обработка изображений

Изображения, отправленные через бота, автоматически сжимаются:

- Адаптивное JPEG-сжатие (целевой размер ~500 КБ)
- Ресайз до максимум 1920px по большей стороне
