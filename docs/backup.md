# Резервное копирование

## Бэкап базы данных

### Создание бэкапа

```bash
./kanban.sh backup
```

Копия сохраняется в директорию `./backups/` с временной меткой в имени файла.

### Восстановление из бэкапа

```bash
./kanban.sh restore
```

Команда предложит выбрать файл из `./backups/`.

## Экспорт и импорт (JSON)

### Экспорт

Администратор может экспортировать всю доску в JSON через интерфейс или API:

```
GET /api/export
```

Экспорт включает:

- Колонки и их порядок
- Задачи с описаниями, приоритетами, дедлайнами
- Спринты, эпики, теги
- Комментарии
- Пользователей (опционально — с хешами паролей)
- Настройки
- Файлы и изображения (опционально)

### Импорт

```
POST /api/import
```

Импорт восстанавливает доску из ранее экспортированного JSON-файла. Все существующие данные будут заменены.

## Рекомендации

- Делайте бэкапы регулярно, особенно перед обновлениями
- Храните копии бэкапов за пределами сервера
- Экспорт в JSON удобен для миграции между серверами
- SQLite использует WAL-режим — бэкап безопасен при работающем сервере
