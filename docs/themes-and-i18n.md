# Темы и локализация

## Темы оформления

Доступно 8 тем:

| Тема          | Описание                          |
|---------------|-----------------------------------|
| **Dark**      | Тёмная тема (по умолчанию)       |
| **Light**     | Светлая тема                      |
| **Ocean**     | Морские тона                      |
| **Forest**    | Лесные, зелёные оттенки          |
| **Nord**      | Холодные северные тона            |
| **Dracula**   | Популярная тёмная тема            |
| **Solarized** | Сбалансированная тёплая палитра   |
| **Spacedust** | Космическая приглушённая палитра  |

Переключение — через меню настроек в интерфейсе. Выбор сохраняется в localStorage браузера и применяется мгновенно.

Темы реализованы через CSS-переменные (`--bg`, `--fg`, `--accent` и др.), что обеспечивает плавное переключение.

## Языки

Поддерживается 10 языков:

| Язык          | Код  |
|---------------|------|
| Русский       | ru   |
| Английский    | en   |
| Китайский     | zh   |
| Испанский     | es   |
| Французский   | fr   |
| Немецкий      | de   |
| Португальский | pt   |
| Японский      | ja   |
| Корейский     | ko   |
| Арабский      | ar   |

Переключение языка доступно в настройках интерфейса. Локализация применяется ко всем элементам UI.

## Размер шрифта

Размер шрифта настраивается в интерфейсе (по умолчанию 18px). Настройка влияет на все текстовые элементы доски.

## Шрифты

Используются локально загруженные шрифты (без внешних CDN):

- **JetBrains Mono** — для кода и моноширинных элементов
- **Source Sans 3** — основной текстовый шрифт

## Адаптивность

Интерфейс адаптирован для мобильных устройств. Доска корректно отображается на экранах разных размеров.

Также поддерживается [WAP/WML](api.md#wap) интерфейс для совместимости со старыми мобильными браузерами.
