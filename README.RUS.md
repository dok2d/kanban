# Kanban — персональная доска задач

[English version](README.md)

Self-hosted канбан-доска, которая работает где угодно без внешних зависимостей. Один бинарник, один файл SQLite, один контейнер — полноценное управление проектами для небольших команд.

## Почему Kanban

- **Ноль зависимостей** — Go + SQLite, никаких Redis, Postgres, очередей сообщений
- **Одна команда для запуска** — `./kanban.sh build && ./kanban.sh run`, открыть браузер
- **Всё включено** — спринты, эпики, теги, вложения, Markdown, комментарии с @упоминаниями, поиск (текст + regex), drag-and-drop, уведомления в Telegram
- **Безопасность из коробки** — rootless Podman, read-only FS, все capabilities сброшены, слушает только 127.0.0.1
- **Работает офлайн** — все статические ресурсы локальные, без обращений к внешним CDN
- **8 тем, 10 языков** — dark/light/ocean/forest/nord/dracula/solarized/spacedust, от русского до арабского

## Быстрый старт

```bash
./kanban.sh build
./kanban.sh run
# → http://127.0.0.1:8080
```

При первом запуске откроется страница создания администратора. Создайте аккаунт и начните работать с доской.

Для деплоя на сервер с TLS за nginx:

```bash
./kanban.sh deploy --host kanban.example.com
```

## Возможности

| Область | Что получаете |
|---------|--------------|
| Доска | Колонки с drag-and-drop, инлайн-редактирование, приоритеты, дедлайны |
| Планирование | Спринты (план → активный → завершён), эпики с цветами и прогрессом |
| Совместная работа | Вложенные комментарии, @упоминания, подписки на задачи, лента активности |
| Организация | Теги, зависимости (блокирует / зависит от), TODO-чеклисты |
| Поиск | Текстовый и regex по задачам, комментариям, тегам и эпикам |
| Файлы | Вложения, вставка изображений (Ctrl+V), Markdown с подсветкой синтаксиса |
| Уведомления | В приложении + Telegram-бот (назначения, упоминания, обновления) |
| Доступ | Три роли: Администратор, Пользователь, Только чтение |
| Данные | JSON экспорт/импорт, бэкапы по расписанию через `./kanban.sh backup` |
| Кастомизация | 8 тем, 10 языков, настраиваемый шрифт, выбор часового пояса |

## Сравнение

| | **Kanban** | Trello | Jira | Notion | WeKan | Planka |
|---|---|---|---|---|---|---|
| Бесплатный и открытый | **Да, MIT** | Freemium | Freemium | Freemium | Да, MIT | Нет (Fair Use) |
| Self-hosted | **Да** | Нет | Data Center ($) | Нет | Да | Да |
| Внешние зависимости | **Нет** (SQLite) | — | Postgres, Elasticsearch и др. | — | MongoDB | Postgres, Redis |
| Время настройки | **~1 мин** | — | Часы | — | ~15 мин | ~10 мин |
| Спринты и эпики | **Да** | Нет | Да | Базовые | Нет | Нет |
| Уведомления в Telegram | **Да** | Нет | Нет | Нет | Нет | Да |
| Офлайн / изолированная сеть | **Да** | Нет | Да (DC) | Частично | Частично | Да |
| Потребление ресурсов | **~30 МБ RAM** | — | 4+ ГБ RAM | — | ~400 МБ | ~150 МБ |
| Темы | **8** | 2 | 1 | 2 | 3 | 1 |
| Языки | **10** | 20+ | 20+ | ~15 | 100+ | 20+ |

Kanban не пытается заменить Jira для компании на 500 человек. Он создан для отдельных разработчиков и небольших команд, которым нужна быстрая, приватная, self-hosted доска, работающая из коробки без инфраструктурных затрат.

## Стек

- **Go 1.22** — stdlib `net/http`, без фреймворков
- **SQLite** — единственная зависимость `mattn/go-sqlite3`
- **Vanilla JS** — без React, Vue и шага сборки
- **Podman** — rootless контейнер с хардингом безопасности
